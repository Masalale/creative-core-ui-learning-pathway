# Creative Core: UI – Learning Pathway

Unity 6 project from the Unity Creative Core pathway, focused on UI.

## Contents
- `Assets/` – scenes, scripts, UI prefabs and assets
- `Packages/` – package manifest
- `ProjectSettings/` – Unity project settings

## Requirements
- Unity 6 (see `ProjectSettings/ProjectVersion.txt`)
- Unity Hub

## Getting started
1. Clone the repo:
   ```bash
   git clone https://github.com/Masalale/creative-core-ui-learning-pathway.git
   ```
2. Open the folder in Unity Hub → Add project → select this folder.
3. Open the main scene from `Assets/` and press Play.
